# ml-churn

ML-сервис для прогнозирования оттока клиентов.

## Стек

- Python 3.13
- FastAPI
- uvicorn
- uv (менеджер зависимостей)

## Установка

```bash
uv sync
```

## Запуск

```bash
uv run uvicorn src.main:app --reload
```

Сервис будет доступен на `http://127.0.0.1:8000`.

## Тесты

```bash
uv run pytest
```

## Docker

```bash
docker compose up --build
```

Сервис будет доступен на `http://127.0.0.1:8000`.
